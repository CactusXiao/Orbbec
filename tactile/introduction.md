一、系统概述与工作原理
1.1 什么是触觉手套？
触觉手套（Tactile Glove）是一种穿戴在手部的传感设备，其内部集成了多个压力传感器，能够实时检测手掌和手指各部位所受到的压力大小。PhlexSensor 手套在手掌区域分布了多达 48 个压力感应通道（8个通道 × 多个手指区域），每个通道对应一个独立的压力感应点。
当手指或手掌接触物体时，传感器受到挤压，其电阻值发生变化，导致输出电压也随之改变。系统通过模数转换器（ADC）将这些模拟电压信号转换为数字值（0–4096），然后经由串口传输到电脑，最终在上位机软件中以曲线图和热力图的形式可视化展示。
1.2 系统架构
整个系统的数据流如下：
压力传感器
→
ADC 转换
→
MCU 控制器
USB 串口
→
电脑接收
→
上位机软件
传感器将物理压力转化为电信号，ADC 将模拟信号数字化，MCU（微控制单元）负责打包数据，再通过 USB 串口将数据发送到电脑，由 PhlexSensorPro 软件负责解析、可视化和存储。

二、基础概念详解
2.1 串口（Serial Port）是什么？
串口（Serial Port）是一种数据通信接口，全称是“串行通信端口”。与并行通信（同时传输多位数据）不同，串口采用逐位依次传输的方式发送和接收数据，就像排队通过一扇窄门，数据一个接一个地通过。
串口的核心参数
参数
含义
本设备设置
端口号
电脑分配给设备的编号
COM1–COMx（取决于插入的USB口）
波特率
每秒传输的比特数（数据速度）
115200 bps（本设备默认值）
数据位
每帧数据的有效位数
通常为 8 位
停止位
标识一帧数据结束的信号
通常为 1 位
 
在本设备中，手套内部的微控制器通过 CH340 芯片将数据从 USB 接口转换为虚拟串口信号。电脑识别后会分配一个 COM 端口号（如 COM3、COM5），上位机软件通过该端口接收传感器数据。
提示：波特率 115200 意味着每秒传输约 115200 位数据。发送端和接收端的波特率必须一致，否则会出现乱码。
2.2 驱动（Driver）是什么？
驱动程序（Driver）是一种特殊的系统软件，它充当硬件设备与操作系统之间的翻译官。操作系统（如 Windows）并不能直接理解每种硬件的工作方式，驱动程序负责将硬件的“语言”翻译成操作系统能理解的标准指令。
一个形象的类比：
硬件设备 = 一个只讲方言的人
操作系统 = 一个只听普通话的人
驱动程序 = 负责双向翻译的翻译官
本设备使用的 CH340 驱动 是专为 CH340 芯片（一种常见的 USB 转串口桥接芯片）开发的驱动程序。安装此驱动后，Windows 才能将插入的 USB 设备识别为一个虚拟串口（COM 端口），并与之通信。
提示：如果不安装 CH340 驱动，电脑会将手套识别为一个“未知 USB 设备”，无法建立数据通信。
2.3 标定文件（Calibration File）是什么？
标定（Calibration）是将传感器的原始电信号与实际物理量（如压力值）建立精确对应关系的过程。
为什么需要标定？
传感器输出的 ADC 原始值（0–4096）并不直接等于真实压力值。由于每颗传感器存在制造差异，即使受到相同压力，不同传感器输出的 ADC 值也可能不同。标定的目的就是通过实验数据建立映射关系，将 ADC 值转换为实际的压力单位。
标定的过程
在实验室中，对传感器施加一系列已知的标准压力
记录每个压力下传感器输出的 ADC 值
通过数学拟合（如线性回归、多项式拟合）得到转换公式
将拟合参数保存为标定文件
标定文件是在出厂前由实验室完成的，用户在正常使用时只需加载该文件即可，不需要自行标定。软件中的“选择标定”功能就是加载对应的标定文件，从而输出经过校准的压力数据。

三、硬件连接步骤
3.1 所需材料
PhlexSensor 触觉手套 × 1
USB 数据线 × 1（手套自带）
Windows 电脑 × 1（Windows 7 及以上）
3.2 连接方式
将手套通过 USB 数据线直接插入电脑的 USB 接口即可。无需额外供电，设备通过 USB 供电和通信。
3.3 验证连接是否成功
右键点击“此电脑”→ 选择“管理”
在左侧导航栏中选择“设备管理器”
展开“端口（COM 和 LPT）”分类
查看是否出现 USB-SERIAL CH340 (COMx) 字样
如果看到该设备名称并且没有黄色感叹号，说明硬件连接正常、驱动已正确安装。记下括号中的 COM 端口号（如 COM3），后续在软件中需要选择对应端口。
�� 提示：如果看到黄色感叹号或显示为“未知设备”，说明驱动未正确安装，需要先安装 CH340 驱动。

五、软件功能详解
5.1 基础设置区（左上角）
端口设置：选择与手套对应的 COM 端口号（从设备管理器中确认），并设置波特率为 115200（默认值，与手套固件匹配）。
连接设置：点击“连接”按钮建立与手套的串口通信。连接成功后，传感器状态会从“离线”变为“在线”。点击“断开”可中断连接。
5.2 操作设置区
功能
说明
曲线显示
选择显示单个手指的 8 通道压力曲线（48 通道全部显示会过于混乱）
开始保存
点击后数据实时存储到 exe 根目录下的 data 文件夹内
选择标定
加载标定文件以输出校准后的数据；选择“ADC 原始值”则输出传感器原始电压值
图像渲染模式
切换右侧 UI 热力图的显示模式（原始模式 / 其他可视化模式）
自动清零
记录当前静态帧作为基准值，后续数据自动减去基础应力，消除传感器的零点漂移
Y 轴设置
可选自适应范围（自动缩放）或手动设置上限/下限值
5.3 曲线显示区域（中部）
中部的折线图实时展示所选手指对应的 8 个通道数据变化。X 轴为采样点序号（时间轴），Y 轴为 ADC 值或标定后的压力值。图例中通道 1–8 分别用不同颜色标识。
5.4 UI 热力图区域（右侧）
右侧的手掌热力图以色温方式可视化呈现所有传感器通道的实时压力分布。颜色从蓝色（低压）到红色（高压）渐变，色标范围为 0–4096。通过热力图可以直观地看到手掌各区域的受力情况。
提示：热力图不支持自动保存。如需记录热力图变化，建议使用屏幕录制软件进行录屏。
5.5 数据表格区域（底部）
底部表格按列显示通道 1–8 的实时数值以及“合力/AD”（所有通道数据的综合值）。数据随采集实时更新。

八、数据文件说明
点击“开始保存”后，采集到的数据会以文件形式存储在 PhlexSensorPro.exe 所在目录的 data 子文件夹中。每次采集会生成新的数据文件，通常为 CSV 格式，包含时间戳和各通道数值，可使用 Excel 或 Python 进行后续分析处理。
