# Label 单关节跟踪

- 在修改后视角中，双击左下角手形示意图的关节，开启当前机位、当前手、当前关节的跟踪；再次双击取消。开启时该点必须可见且坐标有效。
- 单击示意图仍切换可见性，双击不改变可见性。照片中的点和示意图使用黄色外圈表示已开启跟踪；按 `0` 进入总览后，隐藏手形示意图与可见视角数示意图，照片中的关节点仍保留跟踪高亮。
- 仅点击“确认并继续”时，CoTracker 使用当前帧刚确认的坐标，追踪所选且可见的关节，将结果填入下一帧的修改后视角，并保留跟踪选中。普通翻页或时间轴跳转不运行模型。
- 下一帧所选点采用跟踪结果，未选点保留已有编辑或初始化结果。如果下一帧原本已确认，应用跟踪结果后需再次确认。跟踪失败会提示，并保留目标帧原有结果。
- 点的可见性发生变化时自动关闭该点的跟踪，包括单击、框选、忽略视角、撤销造成的变化，以及模型预测为不可见。恢复可见不会自动重新选中，需要再次双击开启。
- 跟踪开关在切换机位和进入总览时保留，在更换任务或退出标注页时清空。开关只在本次标注会话中有效；坐标及可见性仍通过“确认”保存，不写入 `cotrack_2d`。

## 运行依赖

需要 PyTorch 和 CoTracker3 权重。可通过 `COTRACKER_REPO` 指定本地模型仓库；默认先查找 `/home/ubuntu/.cache/torch/hub/facebookresearch_co-tracker_main`，不存在时使用 `label/co-tracker`。模型入口会下载未缓存的权重。

启动时若当前 Python 未安装 PyTorch，Label 会检查当前 Conda 安装中的 `track` 环境，并自动切换到可运行的 Python，保留全部启动参数。也可通过 `LABEL_PYTHON=/path/to/env/bin/python` 显式指定环境。主机现有可用环境为 `/home/ubuntu/WorkSpace/miniconda3/envs/track/bin/python`，已验证 PyTorch 2.6.0+cu124 和 CUDA 模型推理。
