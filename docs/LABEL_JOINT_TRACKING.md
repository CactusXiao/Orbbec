# Label 单关节跟踪

- 在修改后视角中，双击左下角手形示意图的关节，开启当前机位、当前手、当前关节的跟踪；再次双击取消。开启时该点必须可见且坐标有效。
- 单击示意图仍切换可见性，双击不改变可见性。照片中的点和示意图使用黄色外圈表示已开启跟踪；按 `0` 进入总览后，对应机位也显示高亮。
- 向前换帧、时间轴向前跳转或确认后进入下一帧时，CoTracker 使用当前帧的已编辑坐标，仅追踪所选且可见的关节，填入下一帧的修改后视角。其他点保持原有初始化结果。
- 返回旧帧不执行反向追踪；已有缓存修改或已确认的目标帧不会被跟踪覆盖。跟踪失败会提示，并保留目标帧原有初始化结果。
- 跟踪开关在切换机位和进入总览时保留，在更换任务或退出标注页时清空。开关只在本次标注会话中有效；坐标及可见性仍通过“确认”保存，不写入 `cotrack_2d`。

## 运行依赖

需要 PyTorch 和 CoTracker3 权重。可通过 `COTRACKER_REPO` 指定本地模型仓库；默认先查找 `/home/ubuntu/.cache/torch/hub/facebookresearch_co-tracker_main`，不存在时使用 `label/co-tracker`。模型入口会下载未缓存的权重。
