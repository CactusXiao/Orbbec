# Label 视图与 MANO 预览

- **原始视角**：显示原始 MANO 3D 关节点的相机投影，不应用 `joints_vis` 遮挡标记。禁止拖动、可见性修改、撤销和忽略；无法投影的点仍不显示。
- **修改后视角**：首次打开时，以原始投影坐标配合当前相机、当前帧的 `joints_vis` 初始化。已有人工修改优先读取，不被原始值覆盖。
- **两个视角的 Show MANO**：使用与 QC 相同的原始参数、模型、相机标定和实体网格渲染器。进入任务后，在独立后台进程中生成该任务帧的六机位预览；界面读取当前帧、当前机位的缓存。尚未生成时显示渲染状态，不展示其他帧或机位的缓存。切换帧时保持 Show MANO 开关。修改后视角也直接使用同一份原始模型预览，不根据人工点重新拟合、不检查可见机位数；关闭预览后恢复当前编辑。
- **确认并继续**：原始视角、修改后视角及 Show MANO 开启时均可确认。统一保存修改后视角的标注；尚未修改的机位保存应用原始可见性的初始值，原始预览不会覆盖遮挡标记。进入下一帧时保留当前视角和 Show MANO 开关。
- **未确认编辑**：同一任务内，位置与可见性修改按帧、机位和视角分别缓存。切换视角、机位或前后翻帧后可继续编辑；确认当前帧不会清掉其他帧的未确认修改。
- **数字键 1–6**：按照界面机位列表顺序切换六个机位，通常对应 `00`–`05`；切换前缓存当前机位的修改。输入框内输入数字不触发切换。

渲染参数复用 `src/sync/config.json` 的 `frontends.qc` 配置，包含 Python 环境、MANO 工具与模型目录、渲染比例、并发数和 GPU 设置。RGB 缓存通过链接复用，不重复解码。切换任务或退出时取消后台渲染并清理临时预览，不更改 NAS 原始数据。

验证：Label 可见性、视图切换、快捷键、预览隔离和布局共 35 项测试通过；ego 上使用真实 episode 的两帧、六机位生成 12 张预览，验证了机位切换与翻帧的缓存对应关系。
