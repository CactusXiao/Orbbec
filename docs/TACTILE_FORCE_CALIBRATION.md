# 触觉采集力值（N）

主采集程序使用 `tactile/微信图片_2026-09-07_165536_559.jpg` 中的 Hill 拟合参数，将 Shroom/JQ 串口 ADC 总和转换为 N 并保存到 episode。该改动面向 C++ 主采集流程；目录内的 `record_tactile.py` 是独立 ADC 调试脚本，不属于此保存流程。

## 标定含义与范围

CSV 第二列是总力（N），后续 12 列是同时受压的测点 ADC。附图纵轴为 **ADC Sum**，因此转换输入是这 12 列之和，输出是标定区域总力，不能把整条曲线逐点套用或把 256 个通道全部求和。

依据 `tactile/record_tactile.py` 的硬件编号约定，CSV 中传感器编号为 1-based：8、9、10、24、25、26、232、233、234、248、249、250。串口数组对应下标为编号减一。左右手沿用同一组编号和曲线，不额外推断镜像映射。

每个标定测点的力使用 `区域总力 × 该测点 ADC / 区域 ADC 总和` 分配。这是按 ADC 占比得到的估计值，不是逐测点独立标定。区域内测点力之和等于区域总力（文本舍入误差除外）。无接触时为 0 N。

未包含在 CSV 中的通道没有可用的独立力标定，力值为 `nan`，原始 ADC 保留。弯折和未使用通道不会参与总力计算。需要其他区域的 N 值时，应补充对应区域标定及通道映射，不能把当前区域总力标定当成全手标定。

## 图片中的 Hill 转换

固定使用图片参数栏给出的精度：`a = 1257.0210`、`b = 18.2084 N`、`n = 1.1685`。图片公式行将 a 简写为 1257.02；代码使用参数栏的 1257.0210。

```text
S = 标定区域 12 个通道 ADC 之和
F(N) = 18.2084 × (S / (1257.0210 - S))^(1 / 1.1685)
```

使用图片已经拟合好的参数，不重新拟合或插值。零输入输出 0 N；`0 < S < 1257.0210` 按公式原值计算，不截断高值。`S >= 1257.0210` 达到或越过公式奇点，总力和区域各点力写为 `nan`，同时设置 `force_out_of_range=1`。负数或非有限输入同样无有效力值。

默认读取三个 CSV，也可在 `src/sync/config.json` 的 `touch.calibrationPaths` 中只配置其中任意一个。CSV 用于确认参与求和的传感器编号及实测 ADC 范围，不改变上述固定系数。高于所选 CSV 的实测 ADC 上限但仍处于公式定义域内时，继续计算 Hill 力值，并设置 `force_out_of_range=1` 表示外推。

路径相对于配置文件目录解析。加载器支持这批 UTF-8 BOM 和 GBK/CRLF 文件；无接触时零 ADC 对应的微小负力读数可接受。文件缺失、格式错误、通道集合不一致或无有效标定会使手套启动失败，不会回退成 ADC 冒充 N。

对照值：ADC 总和 700 → 22.14 N，1100 → 96.34 N，1200 → 246.96 N，1245 → 965.83 N。图片显示的曲线范围约为 0–100 N；更高力值是该公式在相应输入下的计算结果，不表示图片验证了同等精度。

## 输出字段

episode 内仍使用 `touch/left_raw.csv`、`touch/right_raw.csv`，时间戳及 IMU 字段不变。测量字段更新为：

| 字段 | 含义 |
| --- | --- |
| `calibrated_region_force_n` | CSV 覆盖区域的总力，N |
| `force_out_of_range` | 是否超过实测 ADC 上限或公式无有效结果 |
| `force_000_n` … `force_255_n` | 各通道力估计，N；未标定为 `nan` |
| `raw_adc_000` … `raw_adc_255` | 原始串口数值，ADC，供追溯 |

新的 `touch_manifest.json` 使用 `orbbec.touch.jq_shroom.v2`，记录单位、Hill 公式及系数、图片来源、编号约定、估计方式和越界策略。旧数据不改写；原来读取 `pressure_XXX` 的外部程序需按 v2 字段读取。

独立的 `TactileRecorder::saveSamples` 单帧 CSV 中，`calibrated_value` 和 `output_value` 同样是 N，并附加 `force_unit=N`、区域总力和越界标志；`raw_adc` 仍是原始 ADC。

## 验证

运行 `python3 -m unittest tests.test_tactile_force -v`。测试实际编译 C++ 转换与写出代码，覆盖三份原始文件分别加载和共同加载、通道编号、占比分配、Hill 公式对照和正反算、零输入、奇点及越界、缺失与损坏标定，以及两种 CSV 保存格式。该测试不需要手套硬件。
