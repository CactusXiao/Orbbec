# 外包账号与企业 VPN 入口

用户选择通过企业 VPN 连接。VPN 负责网络可达性，工作台仍独立登录并在服务端检查权限。
已增加独立 VPN 直连入口：启动器通过 HTTPS 连接实验室内网 IP 的 18884 端口，再转发到既有 loopback 工作台。原 SSH 验证入口仍保留。启动包只内嵌服务器公钥证书，不含 SSH 身份或服务器私钥；详见 [VPN 直连说明](vendor_gateway/README.md)。

## 账号使用

首次启动创建 admin，临时密码仅写到私有 `initial-admin.json`（0600）。管理员本人首次登录修改密码后，
通过“账号管理”创建外包人员账号，选择 Label / QC 权限和 Task 范围；不选 Task 表示无任务权限。
“全部任务”是显式授权，包含将来新增任务。任务粒度目前是 Task 名称，不是供应商组织层级。
临时密码经企业既有安全渠道交付，首次登录必须修改；登录链接不含密码或令牌。

修改权限、停用账号、管理员重置密码、用户改密都会撤销该账号已有登录。
退出登录立即撤销当前会话。管理员不能通过网页停用自己或更改管理员权限。
账号凭证和审计记录放在独立 `accounts.sqlite3`（0600）；备份时必须按凭证文件管理。
不要删除账号库重新初始化，这会丢失身份映射与审计，并影响草稿归属。

## 原后端已注册账号

设置 `backend_accounts_file` 为当前原后端实际使用的 `accounts.json` 绝对路径。
管理员在“账号管理”勾选“使用原后端已注册账号”，指定账号及外包角色、Task 范围即可关联，不需要再次设置密码。
注册身份和外包任务授权分开：不会把原后端所有注册账号自动提升为外包管理员或开放全部任务。
当前用户要求接入的 `xjz` 已关联 Label/QC 全任务测试权限，不授予账号管理权限。

关联登录只读原账号文件，直接复用原 `AccountStore._hash_password` 校验；不复制密码或哈希、不重新注册、
不修改原 Label/QC 登录。原后端密码策略保持原样，下面的 15–128 字符新密码要求仅用于新建的外包本地账号。
原账号密码从原账号管理流程修改；外包网页不能改密或重置它，避免生成两个不同密码。
会话绑定原凭证签名，每次访问核验：原后端改密、删除或停用账号后旧会话被拒绝，账号来源无法读取时也不放行。
新旧账号类型和未知账号采用相同的两类密码计算成本；登录限流、外包权限、退出及到期规则继续生效。

## 已实现的服务端限制

- 随机盐 scrypt：N=2^17、r=8、p=1；密码 15–128 字符，不保存明文。最多同时处理两次昂贵密码校验。
- 未知账号和已知账号走同成本密码验证；登录失败不暴露账号是否存在。
- 15 分钟内每账号最多 8 次、每连接来源最多 100 次登录/改密尝试，限流记录持久化。
- 随机会话令牌仅以 SHA-256 存入数据库；HttpOnly / SameSite=Strict cookie。
- 登录最长 8 小时，30 分钟无人操作过期；任务心跳、后台刷新不会延长闲置会话。每账号最多 5 个会话。
- 首次改密完成前任务、媒体和计算接口拒绝访问。
- 每次访问任务、画面、计算、提交都验证角色、Task 范围及 session 的 owner；前端隐藏菜单不是权限边界。
- 写请求检查 Host、Origin、JSON 类型与自定义请求头；无跨域授权。媒体响应 no-store，防止 HTTP 缓存复用已授权响应。
- 浏览器明确保存的草稿仍留本机；退出不删除用户劳动成果。共享系统账号无法提供本地草稿保密性。

配置 HTTPS 后 cookie 同时带 Secure。服务器不信任任意客户端传来的 X-Forwarded-*。
SSH/反向代理场景下来源 IP 都可能是 loopback，因此来源级限流是共同的额外上限，不能声称实现每个外包公网 IP 的独立限流。

## 企业 VPN 正式入口

管理员需提供企业可用域名和受信任 TLS 证书，通过 VPN 网段可访问的反向代理转发到该机 127.0.0.1:18882。
配置文件中设置 `public_origin` 为准确的 HTTPS origin，例如 `https://annotation.example.internal`（示例，未部署）。
代理必须保留该 Host，限制请求体 32 MB、设置合理连接限流，证书应能被外包设备正常信任。
启用后服务仅接受这个 Host/Origin，并设置 Secure cookie；禁止允许任意 Origin 或浏览器跳过证书错误。
原始 NAS 和原工作流 8765 不直接提供给外包用户。

目前已有内网 IP 的 HTTPS 网关和校验证书的本机启动器，外包使用不依赖 SSH。企业域名及浏览器直接信任的证书仍未配置，因此纯浏览器直接访问远端的入口尚未交付。
MFA、企业 SSO、自动离职同步、密码泄漏库校验、完整租户资源配额和独立安全审计尚未实现。
本版采取明确账号/任务权限和会话边界，不宣称已经通过生产安全认证。
